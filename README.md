## English

SortScroller is an addon for ItemScroller that backports the `sortInventory` feature from 1.21+ to older versions.

### Features

- Adds the `sortInventory` functionality to ItemScroller for versions below 1.21

### Requirements

- Minecraft 1.20.x
- ItemScroller or ItemScroller-Forge

### Usage

After installing this addon, the `sortInventory` option will appear in ItemScroller's configuration menu, allowing you to sort your inventory just like in 1.21+.
